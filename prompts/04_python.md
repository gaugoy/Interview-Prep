## Answer frame
1. `**Answer:**` opens with **theory in plain words** (≈ 50–110 words): what it is, how it works
   underneath, why/when it matters.
2. Code only if it helps — one runnable snippet ≤ ~15 lines, comments show output.
3. Optional one-line **Follow-up:** / **Gotcha:**.
4. `**Related:**` links (both directions) to questions that should be learned together:
   `[Topic · QN](./file.md#qN) — <title>`.

## Format
`<a name="qN"></a>` + `## QN. (Easy|Medium|Hard) <Question>`; file header =
title, `### [← Python index](./README.md) · [Question Bank](./Question_Bank.md)`, one-line intro,
**Topics:** nav line, TOC grouped by Part; continuous numbering; `---` between questions.

## Workflow
Duplicate check in `Question_Bank.md` → edit the right topic file (merge overlaps, add Related
both ways) → regenerate that file's TOC, `Question_Bank.md`, README counts / concept map if
affected → validate (shared rules §7) → AGENT_INDEX counts.
